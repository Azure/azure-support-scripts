# Changelog

All notable changes to the RCA Tool extension are documented here.

## [0.1.0] - 2026-06-19

### Added

- Initial release.
- Bundles the `supportfile_mcp` MCP server and `rca_cli` analyzer.
- Registers the `rca-tool` MCP server definition provider for VS Code Agent mode.
- Settings to override the bundled `supportfile_mcp` / `rca_cli` binary paths.
- Platform-specific packages for `linux-x64`, `linux-arm64`, `darwin-arm64`,
  and `win32-x64`.
